## How this works

### Built backward from the end

The plan starts from the questions you need to answer cold at the end ([Final outcomes](#final-outcomes)). Each session's exit ticket is one of them.

### Every session has the same shape

| Minutes | Step | What happens |
|---|---|---|
| 0–3 | **Do now** | 3 due review cards. Rate confidence 1–3, then answer from memory. |
| 3–5 | **Predict** | Today's one objective. Guess first. |
| 5–24 | **Work block** | One small step. You do the core work; Claude explains, points to docs, hints. |
| 24–28 | **Explain back** | Out loud, as if someone asked, then typed into LEARNING.md. |
| 28–30 | **Exit ticket** | The session's question, cold. Write 1–2 review cards. Commit. |

### Three AI lanes

| Lane | What Claude may do | Used for |
|---|---|---|
| **No AI** | Nothing until you're done, then grades | Pretest, solo reps, final retake, the start of each mock |
| **Hints only** | Explain, ask, hint, point to docs. No code for the task. | All core logic |
| **Boilerplate** | Write labeled setup code | {{boilerplate list}} |

### Review cards

[REVIEW.md](REVIEW.md), Leitner boxes. Box 1 comes back next session, box 2 after 2 sessions, box 3 after 4, box 4 after 8. Right: up a box. Wrong: back to box 1. Confident and wrong: box 1 plus a flag.

### Checkpoints are mock interviews

A 10-minute solo rep with no AI, then a fresh agent with a realistic persona that goes one layer deeper on each answer, including a code viva on one of your functions. Pass: the rep works and the mock clears {{BAR}}.

### Keep it worth it

At each checkpoint Claude asks which session felt least worth it, then cuts, merges or reworks what's left.
